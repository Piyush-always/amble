How it works

No app, no screen time and nothing to set up between lessons. Switch it on and it is ready to play.

1

Choose a mode

Turn the knob to pick Sargam or Drum set. The screen shows which one is on.

2

Move near a sensor

A child waves a hand near one of the eight sensors.

3

Hear it straight away

The built-in speakers play that sensor's note or drum as soon as it picks up the movement.

4

Play again

Each sensor keeps its sound, so children can learn it, predict it and build on it.
